### 🎲 Tenzies Game


This is a fun and interactive web-based dice game built with React. The objective is to roll the dice until all of them show the same number. You can click on any die to "freeze" it at its current value between rolls. This version includes a roll counter and a timer to track your performance!

✨ Features
Interactive Gameplay: Roll ten dice and hold the ones you want to keep.

Win Condition: The game celebrates with a shower of confetti when you win.

Performance Tracking: A roll counter and a timer are included to see how quickly you can win the game.

Visual Dice: The dice are styled to look like real dice, with pips instead of numbers for a more authentic feel.

🚀 Getting Started
To get a local copy up and running, follow these simple steps.

Prerequisites
You need to have Node.js and npm installed on your machine.

Installation & Running the App
Clone the repo

```
git clone https://github.com/Sriramm-15/tenzzies.git
```
Navigate to the project directory
```
cd tenzzies
```
Install NPM packages
```
npm install
```
Run the development server
```
Bash
npm start
```
The application will be available at http://localhost:5173/ (or another port if 5173 is in use).
